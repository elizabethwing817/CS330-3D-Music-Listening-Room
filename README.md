# 3D Music Listening Room

**Course:** CS330 – Computer Graphics and Visualization  
**University:** Southern New Hampshire University

---

## Overview

This project was completed for CS330 – Computer Graphics and Visualization at Southern New Hampshire University.

The goal of the project was to recreate a realistic 3D music listening room using OpenGL and C++. The scene was modeled using geometric primitives, textured materials, realistic lighting, and interactive camera controls to demonstrate core computer graphics concepts.

---

## Features

- Interactive 3D environment
- Camera movement and navigation
- Multiple light sources
- Textured objects
- Low-polygon modeling
- Realistic room layout
- Keyboard and mouse controls

---

## Scene Objects

The room includes:

- Record player
- Vinyl storage shelf
- Speakers
- Lounge chair
- Floor lamp
- Plant
- Wall artwork
